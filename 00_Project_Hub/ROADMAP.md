# Project Roadmap

This is the sequence of shared milestones, not a daily task list. The current tasks and owners live in `WEEKLY_PLAN.md`. Update this roadmap when a milestone changes, and record the reason in `DECISION_LOG.md`.

| Phase | Outcome / exit criterion | Status |
|---|---|---|
| 1. Team setup | Names, roles, meeting rhythm, repository and PDF sharing rules agreed | In progress |
| 2. Research scope | Working ablation question; definitions of lightweight and real-time; candidate inputs and target hardware written in Project Home | Not started |
| 3. Literature pilot | Exact searches logged; duplicate-free initial pool; approximately 10–15 key sources screened and discussed | Not started |
| 4. Evidence synthesis | Important baselines, metrics, datasets, and gaps compared across papers; claims linked to sources | Not started |
| 5. Protocol | Model, data splits, ablation matrix, metrics, timing, and reproducibility policy reviewed by both authors | Not started |
| 6. Pilot implementation | Small end-to-end run confirms inputs, alignment, evaluation, and timing tools work | Not started |
| 7. Full experiments | Pre-agreed variants and seeds run; results and failures logged with run IDs | Not started |
| 8. Manuscript completion | Evidence-backed introduction, methods, results, discussion, abstract, and references completed in one LaTeX source | Not started |
| 9. Submission preparation | Venue selected; its template and reporting rules applied; figures and final PDF checked by both authors | Not started |
